# README assets — what to record

The README references images from this folder. Until the files below exist, those
image tags render broken on GitHub, so capture them before pushing.

Capture source: the playground (`../RoroForm-playground`, `./start.sh` → localhost:8000).
Mac capture tool: **Kap**. Keep each clip short (3–5 s), looped, one clear action.
